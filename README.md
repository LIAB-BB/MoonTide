# 月汐 MoonTide

> 抽一张牌，看见空间的潮汐。

月汐是一个把塔罗叙事与可执行空间建议结合起来的黑客松项目。用户扫码进入手机网页、拍摄当前环境、完成洗牌与切牌，并获得 78 张牌正逆位解读和三条可以马上执行的建议。

## 今日验收标准

- 能跑：核心流程稳定完成，并有示例数据兜底。
- 有用：每次结果至少包含三条可执行建议。
- 有意思：抽牌、空间可视化和分享卡片构成完整体验。

## MVP 流程

1. 选择单张 Yes / No 或三张“空间潮汐”牌阵。
2. 拍摄当前环境，并确认场景、光感与整洁度。
3. 完成洗牌、切牌与抽牌动画。
4. 查看 78 张牌的正逆位解读和环境行动建议。
5. 生成结果分享卡片。

## 开发原则

- 优先保证一个完整、稳定、可演示的流程。
- 照片只在用户浏览器中使用，不上传、不保存；所有结果由本地规则生成。
- 不实现账号、支付、数据库、外部视觉模型、精确测量或模型训练。
- 产品只用于娱乐和空间灵感，不提供健康、财务或命运方面的确定性判断。

## 团队分工

- 技术：页面、规则引擎、可视化、部署
