# 月汐 MoonTide

> 抽一张牌，看见空间的潮汐。

月汐是一个把塔罗叙事与可执行空间建议结合起来的黑客松项目。用户选择当前目标、抽取一张塔罗牌，并获得空间能量可视化、布局标注和三条可以马上执行的建议。

## 今日验收标准

- 能跑：核心流程稳定完成，并有示例数据兜底。
- 有用：每次结果至少包含三条可执行建议。
- 有意思：抽牌、空间可视化和分享卡片构成完整体验。

## MVP 流程

1. 选择目标：专注、睡眠、财运、关系或减压。
2. 上传房间照片，或选择预置示例。
3. 抽取一张大阿尔卡那牌。
4. 查看能量雷达、空间标注和行动建议。
5. 生成结果分享卡片。

## 开发原则

- 优先保证一个完整、稳定、可演示的流程。
- AI 和图片上传失败时，自动回退到本地规则及预置案例。
- 不实现账号、支付、数据库、精确测量或模型训练。
- 产品只用于娱乐和空间灵感，不提供健康、财务或命运方面的确定性判断。

## 团队分工

- 技术：页面、规则引擎、可视化、部署
- 产品：范围、流程、验收清单
- 内容：牌义与空间建议
- 视觉：牌面、示例房间、结果卡片
- 路演与测试：反馈、讲稿、现场演示
