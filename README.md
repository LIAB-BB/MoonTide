# 月汐 MoonTide

> 抽一张牌，看见空间的潮汐。

月汐是一个把塔罗叙事与可执行空间建议结合起来的黑客松项目。用户扫码进入手机网页、拍摄当前环境、完成洗牌与切牌，并获得 78 张牌正逆位解读和三条可以马上执行的建议。

## 今日验收标准

- 能跑：核心流程稳定完成，并有示例数据兜底。
- 有用：每次结果至少包含三条可执行建议。
- 有意思：抽牌、空间可视化和分享卡片构成完整体验。

## MVP 流程

1. 选择单张 Yes / No 或三张“空间潮汐”牌阵。
2. 拍摄当前环境，并确认意图、场景、光感与整洁度。
3. 通过浏览器加密随机源洗牌，转动 78 张牌环并凭直觉任选牌面；每张会立刻显示简短提示。
4. 查看 78 张牌正逆位的空间解读、旧金山潮位和环境行动建议。
5. 在页面内预览结果分享卡片，再由用户选择保存；照片默认不进入分享图。

## 开发原则

- 优先保证一个完整、稳定、可演示的流程。
- 照片只在用户浏览器中使用，不上传、不保存；塔罗解读由本地规则生成。
- 旧金山潮位仅从 NOAA CO-OPS 公开预测接口读取，不会发送照片或个人资料；接口不可用时自动降级为无潮位提示。
- 不实现账号、支付、数据库、外部视觉模型或模型训练。
- 产品只用于娱乐和空间灵感，不提供健康、财务或命运方面的确定性判断。
