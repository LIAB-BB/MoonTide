# 22 张大阿尔卡那内容计划

## 数据字段

每张牌包含：

- `id`：稳定英文标识
- `number`：0–21
- `name`：中文牌名
- `keywords`：3–5 个关键词
- `spaceMood`：空间氛围解释
- `actions`：对应专注、睡眠、财运、关系、减压的建议
- `color`：结果页主色
- `icon`：牌面符号
- `warning`：需要避免的空间问题
